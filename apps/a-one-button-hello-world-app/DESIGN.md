# DESIGN — One-Button Hello World

## App: One-Button Hello World · slug `a-one-button-hello-world-app`

### Elevator pitch
The most honest app the AppFactory has ever shipped: exactly one button on
screen. Tap it and the whole app says "Hello, World!"; tap it again and it
keeps greeting you. Bleeding-edge minimal — a single activity, a single layout,
zero dependencies, no internet — so it runs instantly on the oldest low-RAM
phones.

### 1. Screens
| Screen | Purpose | Key content / widgets |
|--------|---------|------------------------|
| Home | The entire app: one button, one greeting | Large centered "greeting" TextView (empty until first press); one full-width button labelled "Say hello"; small hint line underneath |

Empty state: before the first press the greeting TextView is empty and only the
hint ("One button. Go.") and the button are visible — no clutter. Portrait-first
and scales to any phone; the layout fits 480dp-tall screens without scrolling
(three widgets, generous spacing).

### 2. Navigation
- Start screen / launcher: **Home** is the only screen and the launcher
  activity; the app opens straight onto it.
- Flow between screens: none — there is only one screen. There are no tabs, no
  drawer, no detail screen; navigation complexity would defeat the "one button"
  promise.
- Back behavior: the system back button finishes the activity (default
  framework behavior); there is nowhere else to go.

### 3. Visual style
- **Palette**: primary `#6A1B9A` (violet), primary-dark `#4A148C`, accent
  `#FFB300` (amber), screen background `#F7F5FA`, text `#212B36` / secondary
  `#6B5B7B`.
- **Typography**: system font; 34sp bold greeting, 18sp hint, 16sp button label.
- **Spacing/layout**: 24dp screen padding, 32dp gaps between the greeting and
  the button, 48dp minimum touch target (button spans full width).
- **Tone**: playful, minimal, slightly bold — a toy that takes three seconds to
  understand.
- **Light/dark**: light only (`android:Theme.Material.Light`) for v0.1.0.
- Rationale: violet with an amber accent reads "friendly novelty", matching an
  app whose whole point is the joyful first press.

### 4. Interactions
- Press "Say hello": the greeting TextView reveals `Hello, World!`. Each further
  press cycles through a short set of greetings (`Hello, again!`, `Hello,
  hello!`). Feedback is immediate and in-place (no toast, no animation — keeps
  it dependency-light).
- Input validation: none — there are no input fields.
- Error/empty/loading states: no network or I/O, so no loading or error states;
  the only "empty" state is the pre-first-press screen described above.
- Accessibility: the button is full-width with a 48dp height (plus the hint as
  content description context); the greeting is plain text; button label comes
  from a string resource.

### 5. App-icon concept
- **Symbol**: a white circular "press target" ring with a solid amber centre
  dot on a violet tile — a button you want to tap.
- **Colors used**: tile `#6A1B9A`, ring `#FFFFFF`, centre dot `#FFB300`
  (matches the accent in the palette).
- **Background treatment**: solid violet rounded-square tile.
- **Rendering**: legacy PNGs for API 21–25 (mdpi..xxxhdpi, generated by
  `tools/gen-icons.py`) and an adaptive icon (`mipmap-anydpi-v26/ic_launcher.xml`
  + `drawable/ic_launcher_foreground.xml`) for API 26+.
